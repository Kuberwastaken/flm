# FLM · Fly Language Model

FLM is a research implementation of a language model built around fruit-fly connectivity. **ChatFLM** is its browser interface, intended for `flm.kuber.studio` on GitHub Pages.

The project tests whether constrained recurrence, multiple memory timescales and local adaptation can help a model learn from limited human-speech transcripts. It does not assume that biological wiring outperforms other architectures. Claims must be supported by held-out measurements and matched controls.

Implementation is in progress. See `docs/PLAN.md` for milestones and `docs/RESEARCH.md` for the evidence behind the design. Each completed unit of work is committed sequentially.
